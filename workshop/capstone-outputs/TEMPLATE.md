# Capstone 산출물: <닉네임 또는 참가번호> / <YYYY-MM-DD>

> **목적**: 워크샵에서 실습한 흐름을 자사 도메인에 적용할 계획으로 정리한 본인 보관용 1페이지.
> **작성 시점**: 워크북 6-2c 의 3분 슬롯에 본인이 직접 작성. 이어지는 2분 제출은 선택 사항.
> **저장 위치**: `workshop/capstone-outputs/<닉네임 또는 참가번호>_<YYYY-MM-DD>.md` (실명 대신 닉네임이나 참가번호)
>
> **필수 3개 (1, 2, 5번)** 만 채워도 D+1 출발 가능. **선택 4개 (3, 4, 6, 7번)** 는 시간 남으면 / D+1 30분 슬롯에.
>
> **데이터 취급 규칙**: 고객명, 실데이터 값, 기밀 스키마 (실제 테이블·컬럼명), 개인정보는 적지 말고 가명 또는 일반화한 값을 씁니다 (예: 실제 테이블명 대신 "주문 이력 테이블"). 제출하기 전에 소속 조직의 데이터 취급 정책과 고객 NDA 를 확인하세요. 이 폴더의 작성 파일은 `.gitignore` 대상이라 리포에 커밋되지 않습니다.
> **제출 (선택)**: 강사가 회수를 요청한 경우에만, 위 규칙을 지킨 파일을 주최 측이 지정한 승인된 채널 하나로 보냅니다. 제출하지 않아도 본인 보관용으로 D+1 숙제에 그대로 이어 쓸 수 있습니다.
> 본인 보관용 HTML 1페이지가 필요하면 `python scripts/render_capstone.py --name <닉네임 또는 참가번호> --date <YYYY-MM-DD>`.
