# Task code glossary

Short codes such as `R1`, `T2`, `A4`, `I2`, and `X1` appear in source comments.
They are compact labels for the functional areas below.

| Prefix | Functional area |
|---|---|
| `R` | Pipeline and vocabulary-contract restructuring |
| `T` | T-Box quality and collaborative design |
| `A` | A-Box generation and provenance |
| `I` | Inference and justification |
| `D` | Dictionary, data, or deployment support, depending on context |
| `X` | Extended diagnostics and meta-audit |
| `Q` | Quality and validation |
| `P` | Entity resolution and master-data planning |

Use the surrounding function and test name to disambiguate a code. Git history
is the source of change chronology; this glossary explains only the meaning
needed to read current code.
