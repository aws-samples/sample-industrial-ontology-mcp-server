English: [README.md](README.md)

Ontology Agent는 도메인 중립 지식 그래프 라이프사이클을 위한 로컬 stdio MCP
서버 샘플입니다. 동봉 워크샵은 서버 워크플로를 처음부터 끝까지 보여주는 가이드
예시입니다.
